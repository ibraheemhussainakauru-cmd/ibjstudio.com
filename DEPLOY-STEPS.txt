IBJSTUDIO store add-on: what goes where in GitHub (your index.html is NOT touched)

  ibj-store.js                   -> repo root
  _routes.json                   -> repo root
  admin/index.html               -> folder admin/
  functions/_middleware.js       -> folder functions/
  functions/api/[[path]].js      -> folder functions/api/   (keep the double brackets in the name)
  schema.sql                     -> not needed in GitHub; paste it into the D1 console (step 1)

Cloudflare setup
 1. Storage & Databases > D1 SQL database > Create (name: ibjstudio-db) > Console > paste schema.sql > Execute.
 2. Workers & Pages > ibjstudio-com > Settings > Bindings > Add > D1 database > Variable name: DB > pick ibjstudio-db.
 3. Settings > Variables and Secrets > Add (type Secret):
      PAYSTACK_SECRET_KEY = your Paystack TEST secret key (sk_test_...) first
      ADMIN_PASSWORD      = a long password you choose (12+ characters)
      SESSION_SECRET      = any random text, 40+ characters
    (optional, plain variable) NGN_BUFFER_PERCENT = 0   (e.g. 2 adds a 2% cushion for exchange-rate moves)
 4. Re-deploy (push to GitHub, or Deployments > Retry) so the bindings and secrets apply.
 5. Paystack dashboard > Settings > API Keys & Webhooks > Webhook URL (Test, later Live):
      https://ibjstudio.com/api/paystack-webhook
    Callback URL (the site also sends it with every payment):
      https://ibjstudio.com/api/return
 6. Test with Paystack test cards, then swap PAYSTACK_SECRET_KEY to the live key and redeploy.
Admin inbox: https://ibjstudio.com/admin/
